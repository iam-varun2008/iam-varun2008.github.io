Selected work

Built to Detect,
Designed to Explain

Three projects that show how I learn: build the tool, test it in an authorized environment, document the result, and make the work easy to inspect.

01PythonScapyStreamlitNetworkingRule-Based Detection

Network Security Monitor

A Python-based network security monitor that captures live traffic, analyzes packet behavior, applies rule-based detection, records security alerts, and visualizes network activity through a real-time Streamlit dashboard.

Demonstrates packet inspection, network-protocol analysis, behavioral detection rules, persistent reporting, visualization, and automated rule testing.

Demo ↗GitHub ↗
02PythonNetworkRisk

Port Vulnerability Scanner

A Python networking tool that scans authorized targets for selected ports, identifies exposed services, evaluates basic security risks, and generates recommendations.

Demonstrates Python socket programming, service identification, modular program structure, risk classification, and report generation.

Demo ↗GitHub ↗
03PythonLogsDefense

Log Analyzer

A Python log-analysis tool that parses Apache-style logs and identifies patterns such as failed login attempts, admin-path access, repeated 404 errors, request activity, and suspicious behavior.

Demonstrates regular expressions, log parsing, rule-based analysis, IP activity tracking, risk classification, and report generation.
